# VoyageAdvisor10000

An app where you can:

- Create a user
- Create and manage trips
- Book flights
- Find sightseeing spots

## Projects

- **Backend:** ASP.NET Core Web API
- **Frontend:** MAUI app

The frontend and backend can communicate using Tailscale.

## Run the Backend

```bash
dotnet run --urls "http://0.0.0.0:5132"
```

You can also run the backend with the debugger.
